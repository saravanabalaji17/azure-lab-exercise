
# Azure Bastion – Complete GUI Lab Exercise

## Lab Objective

In this lab, you will:

1. Create a Resource Group.
2. Create a VNet with:

   * Application/private subnet
   * `AzureBastionSubnet`
3. Create a private Linux VM **without a public IP**.
4. Verify that direct SSH access from your local machine is not possible.
5. Create Azure Bastion using **Standard SKU**.
6. Configure:

   * Instance count = 2
   * Public IP
7. Connect to the private VM through Bastion.
8. Increase Bastion instance count from **2 → 3**.
9. Test **IP-based connection**.
10. Test **Shareable Link**.
11. Test **Native Client Support**.
12. Validate the complete architecture.

---

# 7. Try Direct SSH

From your laptop/desktop:

```bash
ssh azureuser@10.10.1.4
```

Obviously, replace `10.10.1.4` with your VM's actual private IP.

You should **not** be able to connect directly.

For example:

```text
ssh: connect to host 10.10.1.4 port 22:
Connection timed out
```

### Why?

Your computer is outside the Azure VNet.

The VM has:

```text
Private IP: Yes
Public IP: No
```

Therefore there is no Internet route directly to the VM.

### Important

Don't interpret this as:

> "Private VM means SSH is disabled."

That's not correct.

The VM can accept SSH traffic **from a reachable network**, such as:

```text
Azure VNet
VPN
ExpressRoute
Another Azure VM
Azure Bastion
```

# 8. Create Azure Bastion Subnet

Now go to:

**Virtual networks → `vnet-bastion-lab`**

Select:

**Subnets → + Subnet**

Create:

```text
Subnet name:
AzureBastionSubnet
```

### Important

The subnet name must be exactly:

```text
AzureBastionSubnet
```

For this lab, use:

```text
Address range:
10.10.2.0/26
```

So your VNet becomes:

```text
vnet-bastion-lab
10.10.0.0/16

├── private-subnet
│   └── 10.10.1.0/24
│
└── AzureBastionSubnet
    └── 10.10.2.0/26
```

Save the subnet.

# 14. Validate SSH Connection

You should now get an SSH terminal through the Azure Portal.

Run:

```bash
hostname
```

Then:

```bash
ip addr
```

Then:

```bash
hostname -I
```

You should see the VM's private address.

For example:

```text
10.10.1.4
```

Check the OS:

```bash
cat /etc/os-release
```

Check network:

```bash
ip route
```

Check SSH:

```bash
ss -lntp | grep :22
```

You have now successfully accessed a:

> **Private VM without a public IP through Azure Bastion.**
